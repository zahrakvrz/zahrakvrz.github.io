Thesis: Homomorphic Verification for Dynamic Remote Data Integrity: A Provably Secure Lattice Based Approach

My Master's thesis introduces an interactive protocol for the secure lifecycle of delegated computation. Building on Ring-SIS lattice frameworks, the design allows a data owner to delegate operations to an untrusted server, then interactively verify and authorize the storage of the results. These new data blocks and homomorphic tags integrate directly into the remote data integrity checking architecture, ensuring dynamically generated data is continuously audited alongside original files under formal security proofs in the random oracle model.

Undergraduate Project: Challenges and Applications of Remote Data Integrity Checking Protocols

My Bachelor's project focused on the security and performance analysis of Remote Data Integrity Checking protocols. Through protocol implementation and evaluation, the study examined the architectural trade-offs between formal security proofs and computational overhead in cloud storage systems, focusing on how different cryptographic primitives affect efficiency.
